# airio

KiCad project for the airio schematic. Open `airio.kicad_pro` in KiCad 10;
the schematic starts blank (A4, title block filled in). KiCad will upgrade the
file format on first save.

To point the KiCad MCP server at this project, set
`KICAD_MCP_PROJECT_DIR=hardware/airio` or ask Claude to call `kicad_set_project`.
